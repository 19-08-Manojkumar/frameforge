# Bundled fonts

Unmodified Latin webfont subsets from Google Fonts, downloaded for local serving. Families use SIL OFL 1.1, except Permanent Marker and Satisfy (Apache 2.0). Copyright and full license notices are in licenses/.

- Outfit: https://github.com/google/fonts/tree/main/ofl/outfit
- Playfair Display: https://github.com/google/fonts/tree/main/ofl/playfairdisplay
- Cormorant Garamond: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
- Libre Baskerville: https://github.com/google/fonts/tree/main/ofl/librebaskerville
- Caveat: https://github.com/google/fonts/tree/main/ofl/caveat
- Dancing Script: https://github.com/google/fonts/tree/main/ofl/dancingscript
- Pacifico: https://github.com/google/fonts/tree/main/ofl/pacifico
- Lobster: https://github.com/google/fonts/tree/main/ofl/lobster

- Space Mono: https://github.com/google/fonts/tree/main/ofl/spacemono
