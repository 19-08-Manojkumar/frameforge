# Flag artwork

Unmodified flag SVG artwork from [Twemoji v17.0.3](https://github.com/jdecked/twemoji/tree/v17.0.3/assets/svg), by Twitter, Inc. and other contributors. Graphics are licensed under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/); see `LICENSE-GRAPHICS` in this directory. Only flags listed in the local Unicode emoji catalog are bundled. They load from this application, without a third-party runtime request, and are shared by the picker, preview, and export.
