# Emoji catalog

Fully qualified emoji sequences from Unicode Emoji 18.0.
Source: https://www.unicode.org/Public/emoji/latest/emoji-test.txt
Retrieved: 2026-10-27.

Includes 3963 sequences (including gender and skin-tone variants), with official group and subgroup names. The data is bundled locally and follows Unicode's license in LICENSE.txt. Artwork is supplied by the device's native emoji fonts; newly standardized emoji may require newer OS fonts.
